## [Unreleased]

## [1.5.1] - 2026-11-04

### Changed
- **Menus tick the toggles that are on**: View › Snap, Fill with Color, Dynamic Input, Polar Tracking, Rulers, Grid, Guides, Show Track Lines, Segment Editor › Use Grading and Use Notches, the Grading view items and Marker › View Cut Order and Single Piece Gap. Screen readers hear the state too.
- **Save dialogs start in the folder of the open document**, then in the last folder used for that file type, then in the last folder used at all. Open Backup remembers the backup's folder for the next Save As.
- With two or more segments selected, the Properties row reads "Total length".
- Segment Editor › Copy (`Ctrl+G`) confirms how many points it copied.

### Fixed
- **Where pieces overlap, a click takes the piece drawn on top**, as the hover mark shows. Before, the active piece won even when another piece covered it, so Select, Properties, Space move, paste and the right-click menu could act on a hidden piece.
- **Stack Along Line can be enabled from the Grading Work Area**: a click near an outline now selects that contour segment (a click inside the piece still selects the piece).
- **History names Grading commands** ("Grade notch") instead of their ids.
- **`Esc` after closing a menu disarms the tool** in every workspace; before, the second `Esc` went nowhere until the pointer was back on the desk.
- PDS › Report to Excel: the save dialog no longer says "CSV".
- **Marker Creation Wizard, New Marker and Auto Nest Queue: Browse… and Add Markers… open the file dialog on top**, ready to use. Before, it opened behind the dialog and took no input.
- **Insert to Hole: a piece dragged back into the hole it came from drops in** even when released a few centimetres off; before, only a pixel-exact drop found a hole with no room to spare.
- Auto Nest Queue: new rows start as Regular, so a Marker that is already nested is nested again instead of ending with "Error: nothing to nest". A stopped row shows the efficiency and length of the result it saved, and the end notice counts it as stopped.
- Marker Creation Wizard: piece Buffer is shown in the working unit.
- Marker ruler: the numbers no longer run together when zoomed out.

## [1.5.0] - 2026-11-04

### Added
- **A slit in the middle of a segment, the Optitex way.** Notch Tool, then `Alt+click` on the segment: Notch Properties offers Type **I** (the Optitex name; the label "I (slit)" is now "I"), Depth, Direction Perpendicular and Relationship Proportional, with 0.5 for the middle. The plot, the DXF (layer 4) and the cut file carry it as a slit notch.
- **Extend in Parallel is on the Contour toolbar**, next to Extend.
- **Global Piece Info and Global Internal** (Piece menu). The first selects every piece on the desk, the second every internal line of the selected pieces (all pieces when none is selected); the Properties pane then edits them together, showing "Different" where values disagree, and one edit is one undo step. `Enter` on a selection opens its properties: Point Properties for selected points, else Piece Info.
- **Grading Work Area: right-click menus.** On a point: Copy, Paste, Set Grading Tool, Flip, Grade Equally, Clear, Apply Rule. On a piece: Sizes Table, Set Grading Tool, Stack, Select Grade Points, Create Piece. On the empty desk: Sizes Table and the view items. The object under the pointer is selected first, and a selected run is kept so that Paste reaches all of it.
- **Grading Work Area: rectangle selection** with the Select tool (`Shift` adds), so a run of points can be copied and pasted in one go. There is a hover ring on the point a click would take, and grab marks per size while a drag tool is armed.
- **Set Grading: Last used and Show from Base Size**, as in the Optitex Grading Tool dialog. The last input is kept between openings.
- **Coloured pieces, as in Optitex.** In PDS each piece gets its own fill from a 12-colour palette, pastels in the light theme and deep tones in the dark one. A piece keeps its colour in every size and workspace. Every line stays at 3:1 or better on every fill, and the cut line at 4.5:1. View › Fill with Color (also in the ruler menu) turns the fills off. Marker pieces are drawn more solidly in their size colour.
- **Hover in red, selection in orange.** What a click would hit gets a 2 px ring or outline in the Grade Point red, as Optitex shows its snap; the selection keeps orange. The band and drag ghost are 2 px, and the readout uses 13 px text at 20 px from the pointer. The piece-name tooltip no longer covers the readout: it stays away while a button is held, a gesture runs, or a tool other than Select is armed.
- **Space bar moves the piece under the pointer**, with any tool armed and no button pressed; `Ctrl+Space` moves the internal under the pointer. Releasing Space drops it as one undo step and the armed tool stays. Space still types in text fields and dialogs. A protected piece is refused.
- **File › Open Backup.** Opens the `.bak` of the open Style (or of a Style you pick) as a new, unsaved document, so Save asks where to write instead of overwriting the backup. It is disabled, with the reason, when there is no backup.
- **Tools › Seam › Set Basic Seam**: one seam width on the whole contour of every selected piece, in one undo step.
- **Move Point and Move Point Along Contour preview the new contour** as a dashed outline while the old one dims.
- **Cut Plan: the Create New wizard** (`docs/spec/05-cutplan.md` §1). CutPlan › Create New… walks the Optitex steps Adding Style Files, Defining the Order Details, Adding Colors and Defining Quantity for each Size, Defining Material Properties and Defining the Marker, with Back, Next, Finish and Cancel; Enter goes on, Esc cancels. The first step offers the Style open in PDS before a Style file. An empty Plan, Results or Cut Order pane has a **Create New…** button instead of the text "Use File › …".
- **Cut Plan: estimate-time checks** (`docs/spec/05-cutplan.md` §6). Solve and Nest Markers refuse an ordered piece that is wider than the Material, naming it, before any nesting. The Plan pane and the wizard warn while you edit when a single Bundle is longer than the maximum marker length; its marker is still kept and flagged "too long".
- **Grading › Grade › Grading Notch Tool.** Click a notch, then its previous or next point: a table shows the notch's distance in every size, and Apply grades it in one undo step (Reset brings back what the Style holds). A notch on a point is refused.
- **Marker: Insert to Hole** (`docs/spec/04-marker.md` §5). Piece › Insert to Hole arms a mode beside Select, Shoot and Rotate Piece: drag a placed piece over a hole with the left or right button and it takes the nearest free spot where it fits, turning to any orientation its rules allow if it must, then bumps along the drag like Shoot. One undo step. A fixed piece, a cluster member and a drop with no fitting hole in reach are refused with a notice. Several pieces per drag are not built.
- **Marker: Cluster Pieces and Delete Cluster** (`docs/spec/04-marker.md` §5.1). Grouping › Cluster Pieces freezes the arrangement of two or more placed pieces: they are selected, dragged, nudged, shot, fixed, returned, placed and nested as one piece. A waiting cluster is one Piece Bar thumbnail "Cluster n", placed by double-click or drag. A cluster only translates: turning or flipping a member is refused with a notice. Delete Cluster releases the pieces where they lie.
- **Marker: Optimum Block Fuse and Rectangular Block Fuse** (`docs/spec/04-marker.md` §5.2). Grouping › Optimum Block Fuse… and Rectangular Block Fuse… ask for the gap around the pieces (0 to 1000 mm, 10 mm first) and make a Fuse Block, a cluster with a border. Auto Nesting keeps other pieces out of the border, the plot draws it, and Export Cut File cuts the border instead of the pieces. The second cut file with the block contents and Thrifty Block Fuse are not built.
- **Marker: Cutting Order and Optimize Cut Order** (`docs/spec/04-marker.md` §9.2). Marker › Selected Piece Cut Order… sets one piece's place in the cutting sequence, its start vertex and its knife direction, for that piece or for every placed piece of the same kind. Marker › Optimize Cut Order… orders the cuts nearest-neighbour from the table corner (or from the top), optionally choosing each start vertex. View › Cut/Plot Order, also a status-bar toggle, numbers the pieces and marks each start. Export Cut File follows the order, the start vertices and the directions.
- **Marker: Auto Nest Queue** (`docs/spec/04-marker.md` §6.7). Nesting › Auto Nest Queue… takes several `.rjm` files, each Regular or Continue with its own time and efficiency limit, and nests them one after another on one background job, with no Marker open. Each result goes to `<stem>-nested.rjm` beside its input, which is never written. A file that fails shows its reason and the queue goes on; Stop saves the running row and leaves the others Pending. Closing the dialog keeps the job running, with a strip that names the row. One engine, no queue files, no headless run.
- **PDS: Dynamic Input and Polar Tracking** (`docs/spec/02-pds.md` §2.3, §6.1). Two toggles in the status bar and in View, kept in the preferences. With Dynamic Input (on) Draft takes the typed Length, `Tab` switches to the Angle, `Enter` places the point and `Shift+Enter` makes a Curve Point; `Esc` clears what you typed, and the digit shortcuts stay quiet while it waits for numbers. With Polar Tracking (off) a point near a 45° or perpendicular ray lands on it, with a dashed ray and its angle. Other tools keep their `Alt+click` dialogs.
- **PDS: Point Name.** Add Point on Contour's dialog has a Point Name field, and Point Properties a Name row for selected contour and Internal Line points, one undo step. The name is saved in the `.rjx`; it is not drawn and not written to DXF.
- **PDS: Walk's Support Notch** (`docs/spec/02-pds.md` §6.5). Walk Options gain Support Notch (on), Type and Command (Cut first). While walking, a click on the contour of a third piece walks on along it, from its vertex nearest the junction, and notches the moving piece at the junction in one undo step "Support notch". Reconnect and Grading Walking are not built.
- **PDS: Segment Editor** (`docs/spec/02-pds.md` T90). Tools › Segment Editor has its own clipboard: Copy (`Ctrl+G`) takes the selected run, or the whole contour when one point is selected; Flip X, Flip Y and Inverse turn the copy; Use Grading and Use Notches choose what goes with it. Paste Proportional, Paste Between 2 Points, Paste Notches and Paste As Internal Contour each paste in one undo step and show the fitted run under the pointer. There is no Segment Editor pane and no Use Darts.
- **PDS: Track Lines** (T91). Tools › Track Lines › Track Lines (`Ctrl+Alt+T`) remembers every piece; a changed piece then shows its old contour and internals as a thin dashed ghost while Show Track Lines (`Ctrl+Shift+Alt+T`, also in View and Selection) is on. Restore By Track Line puts the old shape back in one undo step; Clear Track Lines (`Ctrl+T`) starts again from the current shape. Track lines last for the session and are not saved; Snap To Track Lines is not built.
- **PDS: Wave Tool** (T92, Insert toolbar and Design › Contour). Click the first and the last point, move for the height and click: two waves by default, `Tab` and `Shift+Tab` add or remove one, `Alt` on the third click opens the dialog (Waves, Internal Points On Wave, Height, Angle, New Wave or Contour Change). Between two contour points of one piece it reshapes the contour; elsewhere it adds an internal line.
- **PDS: Deform Internals** (T93). Design › Deform Internals › Transform Circle To Contour, Transform Circle To Button and Transform Button To Circle, one undo step each.
- **PDS: Equal Segments** (T94). Design › Equal Segments › Definition… (`Ctrl+Alt+Q`) groups two or more selected runs, in length only or in shape too, proportionally if asked, with Fix Last Point, Mirror and Inverse and a colour; after every edit the other runs follow the one you changed, in the same undo step. A member on a protected piece is skipped with a notice. Show With Color draws the groups in their colour. There is no group list window and no Options.
- **PDS: Fold Line to Line Tool and Swap Piece Properties Tool** (T95, T96, Optitex O/17). Fold Line to Line folds a piece so that one of its lines takes the direction of another. Swap Piece Properties gives two selected pieces each other's name, code, description, quantity, pair, material, label and Marker rules, not their shape.
- **PDS: Zones** (T97). Design › Internal to Piece › Build Zone Tool (click the areas of a map piece) and Trace Zone Tool (click the runs round it) name zones on a map piece; Create Pieces From Map makes one piece per zone, and Correct All Pieces By Map rebuilds those pieces after the map changes, keeping their properties. Swap Zone Segment is not built.
- **PDS: Spread Pieces and Gather Pieces** (T98, Piece › Fabric And Stripes). A spread piece shows a copy for each further quantity and pair beside it, the pair copies mirrored, in the Work Area and in the plot; Arrange For Plot leaves room for them. Gather Pieces removes them.
- **PDS: Fabric And Stripes** (T99). Fabric Pattern… stores the stripe repeat and gap of the fabric, View Fabric draws the stripe grid, Set Stripes Group and Stripes Ungroup number pieces that share a stripe match, and Relate Piece To Stripes marks the point of a piece that sits on a stripe. Nothing is matched in the Marker yet.
- **PDS: Save Placement and Restore Placement** (T100, Piece › General). Save Placement gives every desk piece Fixed Placement; Restore Placement moves fixed pieces back where they were, undoing moves, turns and flips but not point edits, and takes the other pieces off the desk. Fixed Placement is also a check in Piece Properties.
- **PDS: Reopen Darts** (T101, Tools › Darts) opens every dart that Close Dart shows closed.
- **PDS: Piece description layout** (Optitex O/25). Piece Properties › One line prints the description on one line, joined by the Separator; the Work Area, the plot and the DXF label follow. With the Text Tool, drag a piece's description to move it, or `Alt+click` it to set its height and angle.
- **PDS: a colour of its own per piece.** Piece Properties › Color picks the fill of the selected pieces in one undo step; Auto goes back to the palette colour.
- **PDS: the Custom seam corner** (T59). Seam Corner, the Seam Tool corner fields and Point Properties offer Custom, with Depth A and Depth B (5 mm first).
- **Grading: Stack Along Line** (G22). Select one contour segment, then Grading › Stack › Stack Along Line: every size is shown with that run centred and turned onto the Base Size's. Restore Stack clears it.
- **Marker: Text Tool** (`docs/spec/04-marker.md` §5.3, Piece › Internal Text). Click the table or a placed piece to add a text (Size, Angle, X and Y Position); a text on a piece moves and turns with it, and Apply To All Sizes puts it on every placed copy of the piece. Click a text to edit it, Remove it or Remove All; drag it to move it. Texts are plotted, never cut.
- **Marker: Bump/ Cut Lines** (§5.4). Marker › Bump/ Cut Lines… lists the lines with Coordinate, Line Direction, Hide, Fixed, Cut and No Bump, and holds the Marker Top and Bottom overcut, Show Bump Lines Description, Minimal Cut Line Segment and an option that adds a vertical line at the marker end after each Auto Nesting (Optitex O/26). Drag a line out of a table edge, drag it to move it, right-click it for its menu; Marker › Add Bumpline at Current Marker End adds one at the used length. Auto Nesting, the Place commands and Shoot stop at bump lines; the cut file cuts the Cut lines, leaving out what lies inside the pieces; the plot draws cut lines solid and bump lines dashed.
- **Marker: Flaws** (§5.5). Marker › Flaws › Mark Flaw on the Marker (drag a rectangle; Left, Right, Top, Bottom, Whole Length Flaw, Whole Width Flaw), Import Flaws… from a CSV list (`x_from,y_from,x_to,y_to` in mm; a bad line refuses the file and is named), Remove Pieces Hitting Flaws and Delete All Flaws. Auto Nesting and the Place commands keep pieces off flaws, and a flaw never adds to the used length. Flaws are drawn hatched on the table and are not plotted.
- **Marker: Substitute Size For Selected Pieces** (§5.6, Grouping › Bundles). Each selected placed piece swaps with a waiting copy of the same piece in the next size, in one undo step; the order's counts stay right. The last size, or no waiting copy, leaves the piece where it is with a warning.
- **Marker: Single Piece Gap** (§5.7, Tools menu). With a Shoot gap set in Preferences › Marker, Shoot stops that much further from the other pieces, the margins and the bump lines.
- **Marker: Tubular, Faced and Folded ply modes** (§3, §4). They can now be chosen in Marker Properties, Marker Definitions, New Marker and the wizard. Faced and Folded hold a pair piece once, since the opposite ply gives its mirror, and Per garment counts the garments each mode cuts. Half pieces are still nested unfolded, and the pane says so.
- **Marker: Marker Creation Wizard** (§1.1, File menu, Optitex O/22). Pick Style files, name several Markers, order Bundles per Marker and size, set the table, the global properties with the buffer and the rotation, flip and buffer of each piece, then Create Markers opens one unsaved Marker per row. The piece settings go to the Markers' own copies, never to the Style open in PDS.
- **Tools › Theme Settings › System / Dark / Light**, where Optitex keeps it, in every workspace; View › Theme stays.
- **Optitex submenu captions.** Inside a submenu an item shows the Optitex caption when it differs from the tool name: Piece › Info, Contour › Smooth Segment, Join Open Internal Contours, Equal Segments › Definition…, the Segment Editor items, Marker Piece › Internal Text. Toolbars, tooltips, the command palette and right-click menus keep the full name.

### Changed
- **The Grading Table starts with Absolute off**, as Optitex does: it shows steps from size to size, and ticking Absolute shows distances from the Base Size. A value typed before the switch is applied in the view it was typed in.
- **PDS keys follow the Optitex list:** `F7` is Snap (Zoom by Rectangle keeps `Ctrl+Num+`), `Shift+0` toggles Non Grading Points, `Del` with Select deletes the selected sub-objects or else removes the piece from the working area (`Shift+Del` still deletes the piece).
- **Optitex names** for Verify Piece Names, Set Piece Start Point, All To Working Area, Point To Point Fold Tool, Move Points In Parallel Tool, Rotate Counter Clockwise, Global Piece Info, Segment Measurements, Hide/Display Sew Line and Non Grading Point.
- **Marker keys follow the Optitex Marker list:** `Shift+Arrow` shoots the piece to that side, `Shift+N` / `Ctrl+Shift+N` start and stop Auto Nesting (`Ctrl+Shift+Alt+N` opens its setup), `Del` returns the selection to the Piece Bar, `Shift+X` / `Shift+Y` flip, `F3` or `=` rotates 90°, `F4` or `-` rotates 180°, `Shift+R` rotates, `P` is the Place Tool and `Shift+P` places the selected bundles. `Ctrl+M` opens Marker Definitions, `Shift+O` adds a Style, `Ctrl+K` selects the whole bundle, `Ctrl+R` writes the Excel report, `Ctrl+P` prints, `Ctrl+L` opens Plot/Cut and `Z` arms Select. The rajutara-only `F9`, `R`, `F` and `Ctrl+Arrow` are gone.
- **Marker: Optitex names.** Rotate (was Rotate to Next Orientation), Marker Definitions (was Marker Properties), Shoot piece to Left/Right/Top/Bottom, Print (was Report (PDF)), Flip X and Flip Y (was Flip). Export Cut File is now a choice inside Plot/Cut. Rotate to Previous Orientation and Add Style Open in PDS are removed; New Marker still offers the Style open in PDS.
- **Marker: the Piece Bar labels each thumbnail with its piece name**, cut short with "…" inside the cell (the tooltip gives piece, Style and size), instead of overlapping Style-and-size labels. A new or opened Marker fits the fabric width in view, and placed pieces are drawn more solidly in their size colour.
- **A bigger PDS Work Area.** The default layout has the Toolbox column on the left, the Work Area in the middle, Properties in its own column on the right, and one bottom panel with the Pieces Window, Pieces Table, History, Compare Length and Import Report. At 1280×800 the Work Area grows from about 305×740 to 745×395 px. Selecting something no longer hides the Toolbox. Saved layouts keep working.
- **A bigger Grading and Marker Work Area.** The Pieces Window (Grading) and the Piece Bar (Marker) are now the first tab of the bottom panel instead of a strip across the top. At 1280×800 the Work Area panel grows from about 996×316 to 996×432 px. Saved layouts keep working.
- **PDS right-click menus**: the piece and point menus gain a Grading submenu (Sizes Table, Set Grading Tool, Copy Grading, Paste Grading). Internal lines, drill holes and annotations gain Copy Internal Object and Move Or Copy Internal Tool. A selected segment, or two adjacent points, shows a Segment section in Properties (length, Sew/Cut, Straight/Curve). The dead "Custom (not available yet)" button is gone from Point properties, and the empty Work Area has New and Open… buttons.
- **Cut Plan names follow the Optitex help:** Create New, Viewing the Final Results (was Solve), Main Algorithm with Nesting (was Nest Markers), Generating a CutPlan Report (CSV) and (PDF), Viewing the Production Report. The two CSV imports (Import quantities, Import Fabric Rolls) keep their names: Optitex has no import-from-CSV command. Action ids are unchanged.
- **Export Cut File: the knife runs clockwise by default.** A piece used to run in the direction its contour is stored, so the way round depended on how it was drawn. Now every cut runs clockwise unless its Cutting Order says otherwise, starting at the lowest-left vertex unless it names another. A Fuse Block is cut as its border alone.
- **Native format, still version 2.** A `.rjm` can carry optional `clusters` and `cut_order`, and a vertex of a `.rjx` an optional `name`. Files without them load as before and a Marker without them writes no new key. A 1.4.0 build opens a file that has them but drops them, so a re-save there loses clusters, Fuse Blocks, the cut order and point names.
- **Report to Excel writes an Excel workbook (`.xlsx`)** in PDS and Marker instead of a CSV. The Marker workbook has one worksheet per section (General, Order, Pieces, Notches); numbers are number cells. rajutara writes the file itself, so no dependency was added. Cut Plan reports stay CSV and PDF.
- **Cut Plan: a piece wider than the Material is a warning when the file opens**, no longer an error. Solve and Nest Markers still refuse it by name before any nesting, so the plan opens and the Material can be widened.
- **Marker: flaws and bump lines block placement but never add to the used length or the Efficiency**, in Auto Nesting and the Place commands.
- **Native format, still version 2, with more optional content.** A Style can now carry Equal Segments Groups, a Fabric Pattern, zones, Spread, Fixed Placement, Stripe Groups and points, a piece colour and the one-line label; a Marker bump and cut lines, flaws and texts. Files without them load as before and write no new keys. Open these files with this release or later: 1.4.0 opens them but drops that content, and refuses a Style that uses Stack Along Line.

### Fixed
- **Extend takes the typed distance.** The Extend Internal Object dialog opens on the amount field with "By an extension amount" chosen, so a typed length is used without first changing the Reach choice (Contour and Seam are still there). A click on a contour segment no longer does nothing: it is refused with a pointer to Extend in Parallel.
- **Move Piece no longer looks like Select.** The move cross over a piece (Move Piece, Select over a piece it would drag, a slanted guide) is a bitmap the canvas draws itself, not the cursor theme's `move`, which Adwaita (the fallback of the `default` theme) draws as the plain arrow. A tool with no toolbar button (Scale, Segment Length, Fold In and Out, Pleat Lines, Gusset and others) shows its nearest tool's icon on the crosshair instead of a bare crosshair; only Guideline Through, Point Connection and Set Start Point keep the bare one.
- **Grading a point by typing.** The dX/dY cells of a point without a rule were disabled, so typing did nothing and the digits fired shell shortcuts. Typing now grades the point and makes it a Grade Point. A typed value is kept when the selection moves on without `Enter`, and it no longer overwrites a following Equal All.
- **Move Point Size takes the size of the point you grab**, as Optitex does, instead of only the size shown in the legend. The dragged point becomes the selection, so the Grading Table shows its new grading, and the drag shows a band with L, angle, dX and dY.
- **Equal and Equal All start from the first size**; Zero, Flip and Equal act on the clicked column. Before, Equal All used the size above the base and erased a value typed in the smallest size.
- **Graded pieces are marked once.** The selection tint, outline and corner ticks were drawn once per size, so four sizes covered the size lines with a nearly solid orange. Only the Base Size item carries the selection mark now.
- **The Sizes legend can be dragged and collapsed** and stays inside the Work Area.
- **The Snap toggle reaches the tools.** `F7`, or Snap in the status bar, turns snapping off for every PDS tool; before, the tools always snapped and `Ctrl` was the only way to stop it.
- **A Cut Plan with a piece wider than its Material opens.** 1.4.0 refused the whole file, so the Material could not be widened to fix it.

### Removed
- **Add Point at Midpoint** (`Alt+O`), Add Point on Contour's midpoint-only mode and its snap to the middle of a segment. Optitex has none of them; the Optitex way to put a point in the middle of a segment is Add Point on Contour, `Alt+click`, Proportional 0.5.

## [1.4.0] - 2026-11-02

### Added
- **Sizes Table: line thickness per size, Insert and Append continue the step everywhere, Regrade by Break Size covers all pieces** (`docs/spec/03-grading.md` §3). A Thickness column sets each size's line in the Graded Nest (0.05 to 5 mm, default 0.25; the Base Size is drawn 0.10 mm thicker); files without it load with the default and the native format gains `thickness_mm` on each size. Insert and Append Sizes continue the step of the two nearest sizes in the middle of the table too, not only at the ends. Regrade by Break Size in the dialog regrades every unprotected piece, whatever is selected.
- **A pointer for every tool** (`docs/spec/07-ui-shell.md` §4.3). The armed tool's icon sits on a crosshair; Select shows the move cross over a piece it would drag and a crosshair over a point, notch or internal line; Move Piece shows the move cross, Text an I-beam over a piece; every tool that edits shows "not allowed" over a protected piece (Select, Measure and the other read-only tools keep their pointer). The canvas's own gestures win: grab while panning or holding `Shift`, resize arrows over the ruler bands and on guide lines, a zoom pointer for zoom by rectangle.
- **Selection, active and hover marks.** A selected piece has a heavier outline and a tint, the active piece a heavier outline, a stronger tint and four corner ticks, a selected vertex a larger filled glyph, a selected segment a thick stroke. Hovering shows what a click would hit: a ring round a vertex, a heavier notch or internal line, the outline of a piece not selected yet.
- **Piece Information Text on the desk and in the plot** (View › Piece Information Text, on by default; also a check in View and Selection). Each piece shows its label fields, one per line, at its label anchor and turned with it. The plot prints the same lines.
- **Rubber bands and live readouts** for every tool that takes a second point (`docs/spec/02-pds.md` §6.1). From the first pick a dashed band follows the pointer to the point the next click would use, with Length, Angle, dX and dY or the tool's own numbers (radius of Arc and Circle, depth of a Dart, distance along the contour, length of a run). Rectangle selections draw a marquee.
- **The armed tool is marked** on its toolbar button, its Toolbox button and in the status bar, which names it before the prompt (`Move Point: Click the point to move…`). Marker marks its mode the same way.
- **Design › Add › Add Point at Midpoint** (`Alt+O`, Insert toolbar, `docs/spec/02-pds.md` §6.6). A point goes at half the arc length of each selected segment, or of the segment between two selected adjacent points, and the new points become the selection; one undo step names each piece once. A locked piece among the targets refuses it with a notice. With nothing selected it arms Add Point on Contour in midpoint-only mode: each click splits the segment under it, `Esc` leaves.
- **Add Point on Contour previews its spot** with the distances from the previous and to the next point and the ratio, and snaps to the middle of a segment within the snap radius (`Ctrl` or Snap off turns that off).
- **Move Point and Move Point Along Contour work by dragging** (T29, T30): press the point, drag, release. Click, click still works. A press becomes a drag after 4 px at any zoom, so short drags at high zoom are no longer lost, and `Esc` during a held press ends the gesture, not the tool.
- **Extend in Parallel asks for the distance in a dialog** once the first and the last point of the edge are picked (positive extends, negative trims), as Create Parallel does. Cancelling the dialog leaves nothing picked; the old third click that set the distance is gone.
- **Marker: New Marker is one modal** with the Marker Definitions, the Style (the one open in PDS, or a file with Browse), the Material (with the pieces one Bundle takes of each) and the Bundles and direction per size. Create is blocked with its reason until a Style is chosen and something is ordered.
- **Marker: Pieces pane** (View › Pieces, first tab on the left): a table per Style with `placed/total` for every piece and size and a Total row. Click selects a cell's placed pieces and arms placing, double-click places the next copy, drag places at the drop point, right-click places or returns a whole size.
- **Marker: place by click.** A click on a Piece Bar thumbnail or a Pieces cell arms placing; the next copy hangs under the pointer as a ghost in its Size colour, hatched red where it would overlap, and each click on the table places it. `Esc` or a click on bare bar space stops. An empty Piece Bar now says whether there is no Style or nothing ordered. Each placed piece shows its plot label inside it.
- **Marker: Auto Nesting runs in its dialog.** Start shows elapsed time against the Time limit, the best length and Efficiency so far and the pieces placed, with **Stop** (`Esc`); a summary follows. Auto Nesting Setup has **Save**.
- **Right-click menus in the Work Area** (`docs/spec/02-pds.md` §6.7). The object under the pointer is selected first, then a menu offers what applies to it: on a segment Add Point at Midpoint, Add Point on Contour, Notch, Segment Length, Add Seam, Rotate to Horizontal and Baseline Parallel to Segment; on a point its properties, Toggle Grade/Curve Point, Notch on Point, Move Point and Delete; on a piece Piece Info, Lock, rotate, flip, copy, cut, remove and delete; on the bare desk Select, Paste, Select All, All to Desk, Zoom All and the Piece Information Text and Guide Lines checks. A Draft in progress keeps the right button for its arc.
- **Properties follows the pick** (`docs/spec/02-pds.md` §4.3). A pick on the canvas brings the Properties tab to the front of its panel without taking the keys from the canvas, the section of the object picked last comes first, and a point, notch or line pick folds the Piece section into one `Piece: <name>` line. Preferences › Tools › Show Properties when picking turns it off.
- **Edit › Undo and Redo name the command** they act on (`Undo: Move piece`), in the menu and in the toolbar tooltips.
- **Tool pop-ups match Optitex** (`docs/spec/02-pds.md` §4.3): Alt+click with the Dart tool asks Width, Depth, Overlap, Drill Distance and Drill Radius and adds the dart there; the Seam dialog has Start and End Corner and Set Last Width; Walk Options has Skip Open Pleats in the Optitex order; Notch Properties has Reverse (L notch); Add Point on Contour has Distance According To Grading Points and Move Along Contour; Alt+click with Create Parallel on a segment asks the distance for that segment; Piece Properties has Task Pieces (Selected or All) and an Adjust button for the label; Marker Properties shows the Total Pieces Area.
- **Notches plot and preview in their real shape** (I, V, T, Box, U and L with Reverse) instead of one depth line.
- **Marker: Fix on Marker** (Piece › Fix on Marker, Unfix Selected, Unfix All, and the Pieces cell menu; `docs/spec/04-marker.md` §5). A fixed piece shows a pin, refuses drags, Shoot, nudges and turns with a notice, and stays where it is during Auto Nesting even when Keep placed pieces is off. Returning it to the Piece Bar frees it; one Undo puts it back fixed. Files written before 1.4.0 load with nothing fixed.
- **Marker: Marker › Marker Definitions…** opens the Marker Properties fields as a dialog; OK applies them as one undo step. **Marker › Report…** shows the Report pane, also when it was closed.

### Changed
- The keypad shortcuts are back (`docs/spec/07-ui-shell.md` §6.2): `Num+` zooms in, `Ctrl+Num+` zooms by rectangle, `Ctrl+Shift+Num+` toggles the rulers and `Shift+=` flips horizontally, told apart from the main-row keys by the physical key. `Plus`, `F7`, `Ctrl+Shift+=` and `Alt+=` keep working.

- A piece dragged from the Pieces Window onto the canvas lands with its centre on the drop point.

- Move Point Along Contour slides a vertex from Grade Point to Grade Point, passing the Turn and Curve Points between them and taking its new place in the contour; it used to stop at its two neighbours. ### Fixed

## [1.1.0] - 2026-11-01

Renamed from optirust to **Rajutara** (*rajut* = knit, *tara* = balanced). Native files are now `.rjx` / `.rjm` / `.rjc`; the old files still open.

### Added
- Start-up splash like LibreOffice's: a small (640 × 262), centred, borderless window with the owner's artwork, a real progress bar and a status line (language, icons, modules, layout, each file argument), shown at least 600 ms. It then becomes the workspace window in one frame (decorations on, no fade). The workspace opens **maximized** on first run; after that the size, position and maximized state of the last quit are restored from `window.json` in the config directory. `--smoke` still opens one fixed 1280 × 800 window with no waiting, so `first_frame_ms` still measures the time to a usable canvas.
- Help › About credits the artwork to the project owner.
- History pane: hover a row to preview that step on the canvas (read only, nothing is undone), piece names and a relative time ("2 min ago") on each row, a disk mark on the row where the document was last saved, and a session-only "Compare with before" toggle that draws the pieces the last command touched as dashed grey ghosts of the previous step. `History::peek`, `History::entries`, `History::saved_generation` and `Command::touched` are new in `rajutara-core` (additive); `Document::mark_saved` now records the saved generation in the `History`.
- **Theme mode.** The theme can now follow the operating system: `System` is the new default next to `Dark` and `Light`, applied every frame so an OS change shows at once (dark where the system does not say; Windows 7 reports light). A three-button control (System, Dark, Light) sits at the far right of the menu bar; View › Theme and Preferences › Appearance stay in step with it. Preferences are now version 2; a saved `Light` or `Dark` is kept, and a 1.0 build refuses the newer file instead of misreading it.
- **Update check and self-update** (`docs/spec/07-ui-shell.md` §14, ADR-0015). Once a day at start-up, silently, Rajutara asks GitHub for the latest release (`update.repo`, default `madmouse17/rajutara`; Preferences › General switches it off). While a newer release exists an orange **Update available · v1.x** button appears left of the theme control and opens a dialog with the release notes and **Download and Install**; Help › Check for Updates… checks on request and always answers. Linux replaces the AppImage atomically and offers **Restart Now**; Windows runs the `.msi` through `msiexec` after **Install and Close**. New dependency `ureq` 3 (`rustls`, `json`; no OpenSSL, no async runtime); `deny.toml` and `about.toml` allow `CDLA-Permissive-2.0` (the `webpki-roots` data) and skip the duplicate `getrandom` 0.2. Debug builds honour `RAJUTARA_FAKE_UPDATE=1.9.9` to show the button without a request.
- **Welcome screen.** While PDS or Grading has no document, the Work Area shows a card with the logo, **New Style**, **Open…**, **Import DXF…**, **Open sample "Kaos Lengan Pendek"** and the five newest recent files. The sample is compiled into the program and written to `samples/` in the config directory each time it is opened.
- **File › Close** (`Ctrl+Shift+W`) closes the active document. A document with unsaved changes asks Save / Don't Save / Cancel first (`Esc` is Cancel); its autosave file goes with it. Quitting and the window's close button ask the same way.
- **File › Open Recent** keeps the newest 10 files of each kind (Style, DXF, Marker, Cut Plan), groups them by kind, moves a file to the front on every open and save, and greys out files that are gone. It was a single list of 8.
- **Drag and drop:** files dropped on the window open by extension (`.rjx`, `.rjm`, `.rjc`, `.dxf`); any other file gets a notice.
- **Toolbox search** (View › Search Tools): filters the tools live by English, Indonesian or Optitex name; `Enter` runs the first match, `Esc` clears; `/` while the Toolbox pane is focused, or typing with keyboard focus on a tool button, starts the search. It has no chord: `Ctrl+Shift+F` stays Optitex's Fold Out.
- **Renamed from optirust.** Files with the old `.optx`, `.optm` and `.optc` extensions still open (File › Open, drag and drop, command line; the open dialog lists them under "Legacy optirust files"); they open untitled and Save writes `.rjx`, `.rjm` or `.rjc`. On the first run the old `optirust` config directory (preferences, layouts, window) is copied into `rajutara` once. The AppImage registers MIME types for all six extensions.
- Toolbar and Toolbox tooltips read `Name  · shortcut  · Optitex: name`.
- `Ctrl` + wheel pans the canvas horizontally and `Shift` + wheel vertically; the wheel map is in `docs/spec/07-ui-shell.md` §4.1. Ctrl + wheel no longer zooms; pinch still does.

## [1.0.0] - 2026-11-01

First release. Clean-room apparel CAD for Linux (reference) and Windows 7+ (cross-built), see `docs/adr/`.

### Added
- **PDS** workspace: 89 pattern tools (drafting, points, notches, seams, darts, pleats, walk, mirror, split/join, fullness, spiral, gusset), Pieces/Properties/History panes, Plot (tiled A4, A0, HPGL/2).
- **Grading** workspace: Size Table, Grade Rules, Rule Table, Graded Nest view, 29 grading tools, ASTM graded-nest + RUL export.
- **Marker** workspace: manual placement (drag, rotate, flip, bump, Shoot), automatic nesting engine (no-fit polygons by ring convolution, bottom-left fill, simulated annealing; deterministic by seed; `Stop::Time` is a hard wall-clock limit), marker report, HPGL/2 plot and cut file.
- **Cut Plan** workspace: orders (ratio mode, CSV import), lay planning solver, nesting, consumption and cost, Cut Order with Fabric Rolls (sequence, roll allocation, remnants), CSV/PDF reports.
- Interchange: ASTM D6673 / AAMA-292 DXF import and export, RUL grade-rule files; native `.rjx` / `.rjm` / `.rjc` (zip + JSON, format 2).
- Shell: dockable panes, command palette, keyboard shortcuts, light/dark theme, English and Indonesian UI, autosave with crash recovery, `--smoke` self-check.
- Packaging: Linux AppImage; Windows x64/x86 `.zip` (portable) and `.msi` (installer) with optional Mesa software OpenGL, Windows 7 SP1 through Windows 11.

### Known limits
- Windows builds are verified under Wine and the import gate only; real-hardware run pending.
- 3D (Runway equivalent) is interface-only (ADR-0005).
- Vendor cutter drivers are not included; the cut file is generic HPGL/2 only.
