---
title: Glosarium
description: "Kosakata Rajutara: style, potongan, kontur, aturan grade, marker, lay, dan lainnya."
---

Halaman ini memuat kosakata Rajutara. Setiap istilah juga menjadi nama tipe dan modul di kode, jadi kode, menu, dan halaman ini memakai kata yang sama. Istilah ditulis dalam bahasa Inggris karena itulah nama di kode; padanan Indonesia yang dipakai antarmuka ada di kolom Arti. Kolom ketiga memuat kata yang di proyek ini berarti lain atau mudah tertukar dengan istilahnya.

| Istilah | Arti | Hindari |
|---|---|---|
| **Style** | Desain garmen sebagai sekumpulan potongan pola beserta tabel ukuran dan aturan grade-nya. Satuan yang disimpan sebuah dokumen. | Model, design file, project |
| **Piece** | Satu komponen pola dari style (Potongan), dibatasi kontur potong tertutup, membawa notch, Garis Serat, garis dalam, dan anotasinya. | Panel, part, pattern |
| **Contour** | Garis tepi tertutup sebuah potongan: urutan segmen (garis, Bézier kubik, busur). Kontur potong adalah yang terluar; kontur jahit adalah kontur potong dikurangi kampuh. | Outline, boundary, path, polygon |
| **Seam Allowance** | Pita antara kontur jahit dan kontur potong (kampuh), dengan lebar per segmen. | Margin, offset, SA |
| **Notch** | Tanda pada kontur yang menyelaraskan potongan saat menjahit (penandaan). Punya bentuk (V, T, I, L (check), U, Box), kedalaman, dan lebar. Box adalah notch "castle" ASTM D6673 (layer 81). | Clip, snip, mark, castle |
| **Grainline** | Garis berarah pada potongan (Garis Serat) yang harus sejajar dengan lusi kain saat penataan marker. | Grain, arrow, warp line |
| **Size Table** | Daftar berurutan ukuran yang menjadi target grade sebuah style, dengan satu base size. | Size range, size set |
| **Grade Rule** | Perpindahan X/Y satu titik potongan (kontur, garis dalam, lubang bor, atau ujung Garis Serat) dari base size ke setiap ukuran lain. | Grading increment, growth, delta table |
| **Marker** | Tata letak potongan satu style atau lebih dan satu ukuran atau lebih pada kain dengan lebar tertentu, siap diplot atau dipotong. | Layout, nest, lay plan |
| **Marker Table** | Kanvas ruang kerja Marker: pita kain selebar Material Marker tempat potongan ditata. X membentang sepanjang panjang marker (lusi), Y melintang lebarnya. | Canvas, desk, work area |
| **Piece Bar** | Jalur di ruang kerja Marker yang menampung instans potongan yang masih menunggu ditata: satu thumbnail per Style, potongan, dan ukuran dengan sisa jumlahnya. Urutannya menjadi benih Nesting. | Piece tray, palette, queue |
| **Piece List** | Tabel ruang kerja Marker dengan satu baris per potongan dan ukuran dari Style yang tertanam, tempat properti khusus Marker (kode, material, jumlah, rotasi, balik, buffer) disunting pada salinan yang tertanam. | Pieces Table (panel PDS), parts list |
| **Cluster** | Dua potongan atau lebih yang sudah ditata di Marker, yang mempertahankan susunannya dan dipindah, ditembak, serta di-nesting sebagai satu potongan. Selama menunggu, Piece Bar menampilkannya sebagai satu thumbnail. | Group, bundle (Bundle adalah potongan satu permintaan ukuran), assembly |
| **Fuse Block** | Cluster dengan batas (persegi panjang di sekeliling potongan atau kontur yang mengikutinya, pada celah tertentu) yang dipotong oleh Export Cut File alih-alih potongannya, sehingga blok bisa di-fuse sebelum potongannya dipotong. | Fusing zone, interlining block |
| **Cutting Order** | Urutan potongan sebuah Marker masuk ke mesin potong, dengan titik awal dan arah setiap potongan. Bukan Cut Order milik Cut Plan. | Cut sequence, plot order, Cut Order (itu milik Cut Plan) |
| **Bump Line** | Dinding vertikal atau horizontal pada Marker yang tidak dilewati potongan selama Nesting dan Shoot. Bump Line juga bisa berupa Cut Line, atau garis No Bump yang boleh dilewati potongan. | Wall, barrier, stop line |
| **Cut Line** | Bump Line bertanda Cut yang dipotong oleh berkas potong: yang vertikal melintang kain dengan overcut di setiap ujung, yang horizontal memanjang kain sampai panjang terpakai. Bagian di dalam potongan dan bagian yang lebih pendek dari Minimal Cut Line Segment dilewati. | Cross cut, split line |
| **Flaw** | Persegi kain, ditandai pada Marker (cacat kain), yang dijauhi setiap potongan oleh Auto Nesting dan perintah Place. Flaw bisa membentang sepanjang seluruh marker atau selebar seluruh Material. Flaw tidak pernah menambah panjang terpakai. | Defect, hole, damage |
| **Nesting** | Tindakan menata potongan pada marker, dengan tangan atau algoritma, untuk meminimalkan panjang kain. | Packing, layout, optimisation |
| **Lay** | Setumpuk lapis kain yang dipotong bersama di bawah satu marker (hamparan). | Spread, ply stack |
| **Order** | Jumlah sebuah style per ukuran dan warna yang harus dipenuhi perencanaan potong. | Job, production order |
| **Base Size** | Satu-satunya ukuran di Size Table yang geometri potongannya digambar; setiap ukuran lain diturunkan darinya oleh Grade Rule. | Master size, sample size, reference size |
| **Ply** | Satu lapis kain dalam sebuah Lay. | Layer, sheet |
| **Plot** | Keluaran marker atau potongan berskala 1:1 ke plotter (HPGL/2) atau ke PDF, termasuk PDF berubin untuk printer kecil. | Print, export drawing |
| **Operator** | Orang yang memakai rajutara di bengkel garmen: pembuat pola, grader, atau pembuat marker yang terlatih di Optitex. | User, designer, admin |
| **Turn Point** | Titik kontur tempat garis boleh berbelok tajam. Dua Turn Point tanpa Curve Point di antaranya dihubungkan garis lurus. | Corner point, anchor, node |
| **Curve Point** | Titik kontur yang dilalui kurva mulus; Curve Point berurutan membentuk satu kurva. | Spline point, control point, handle |
| **Grade Point** | Titik potongan yang membawa Grade Rule-nya sendiri. Titik kontur tanpa aturan bergerak sebanding dengan Grade Point di sekitarnya. | Rule point, cardinal point |
| **Internal Line** | Garis di dalam potongan yang digambar, dipotong, atau dijahit tetapi bukan bagian dari konturnya. | Internal, inner line, drawing line |
| **Drill Hole** | Titik di dalam potongan yang dilubangi atau ditandai saat potongan dipotong, dengan diameter opsional. | Punch, hole, button |
| **Annotation** | Teks yang ditempatkan pada potongan dan diplot bersamanya. | Label, comment, note |
| **Mirror Line** | Tepi lurus potongan separuh yang menjadi sumbu potongan itu terbuka menjadi potongan utuh yang simetris. | Fold line, symmetry line, half line |
| **Dart** | Baji kain yang diambil dari potongan (kup), ditentukan oleh dua kaki pada kontur dan satu ujung. | Tuck, suppression |
| **Pleat** | Lipatan kain yang dimasukkan ke potongan dari kontur (lipit), ditentukan oleh garis lipatnya, jenis (knife, box, axe), dan kedalaman. | Tuck, fold |
| **Track Line** | Bayangan tipis putus-putus sebuah Piece seperti saat Track Lines dinyalakan, hanya base size, beserta objek dalamnya. Bertahan selama sesi dan tidak disimpan. Restore By Track Line mengembalikan bentuk yang diingat. | Trace, history line, undo ghost |
| **Zone** | Area pada Map Piece yang ditandai dengan mengklik di dalamnya (Build Zone) atau dengan menelusuri deret yang membatasinya (Trace Zone). Create Pieces From Map mengubah setiap Zone menjadi Piece. | Region, area, section |
| **Map Piece** | Piece yang memuat Zone: sketsa datar garmen yang area-areanya menjadi Piece sebenarnya. Piece yang dibuat darinya mengingat Zone-nya, sehingga Correct All Pieces By Map bisa membangunnya ulang. | Block, master piece, base pattern |
| **Equal Segments Group** | Deret kontur atau Internal Line dalam satu Style yang tetap sama selama Operator menyunting: hanya panjangnya, atau juga bentuknya. Deret yang pertama disunting memimpin dan yang lain mengikuti. | Linked segments, match group, sibling lines |
| **Stripe Group** | Nomor yang diberikan pada Piece yang berbagi satu pencocokan belang atau kotak-kotak di Marker. Relate Piece To Stripes menandai titik Piece yang berada di garis belang. | Match group, pattern group |
| **Spread Pieces** | Piece yang diberi tanda sehingga Work Area dan Plot menampilkan satu salinan turunan untuk setiap Quantity dan Pair berikutnya di sampingnya. Gather Pieces menghapus tandanya. Bukan penghamparan sebuah Lay. | Duplicate, copy pieces, array |
| **Material** | Kain bernama tempat potongan dipotong. Sebuah Marker dibuat pada satu Material, yang menyediakan lebar, mode lapis, penyusutan, dan biayanya. | Fabric type, cloth, textile |
| **Ply Mode** | Cara setiap Ply sebuah Material terhampar di meja: tunggal (terbuka), tubular, berhadapan (muka ke muka), atau terlipat. | Layout mode, spread type, fabric layout |
| **Bundle** | Kumpulan potongan yang membuat satu garmen satu ukuran dari sebuah style. Sebuah Marker meminta sejumlah Bundle per ukuran. | Set, kit, garment |
| **Buffer** | Ruang ekstra yang dikosongkan di sekitar potongan dalam Marker. | Gap, clearance, spacing |
| **Efficiency** | Luas potongan yang ditata dibagi lebar Marker kali panjang terpakainya, dalam persen. | Utilisation, yield, usage |
| **Graded Nest** | Semua ukuran sebuah potongan yang ditampilkan atau diekspor bersama, diselaraskan pada Stack Point. | Size stack, nest |
| **Stack Point** | Titik atau Garis Serat tempat ukuran-ukuran sebuah Graded Nest diselaraskan untuk tampilan. Memilihnya tidak pernah mengubah geometri atau Grade Rule. | Anchor point, reference point |
| **Rule Table** | Kumpulan Grade Rule bernomor yang disimpan bersama Style, disalin ke Grade Point, dan dipertukarkan sebagai berkas ASTM RUL. | Rules library, rule file, RUL |
| **Cut Plan** | Lay-lay, masing-masing sebuah Marker dengan jumlah lapis, yang bersama-sama memotong sebuah Order dari satu Material, beserta panjang kain dan biaya yang dihabiskannya (Rencana Potong). | Cutting plan, spreading plan |
| **Cut Order** | Urutan Lay sebuah Cut Plan dihampar dan dipotong, beserta Fabric Roll tempat tiap Lay mengambil Ply-nya. Optitex menyebut seluruh rencana sebagai "cut order"; di rajutara itu adalah Cut Plan. | Spreading order, cutting sequence, roll plan |
| **Fabric Roll** | Satu gulungan sebuah Material dalam satu warna Order sebagaimana datang dari Fabric Room, dengan kode, Shade, lebar, dan panjangnya. Setiap Ply diambil utuh dari satu Fabric Roll. | Bolt, piece goods, roll stock |
| **Shade** | Kelas nuansa warna tempat sebuah Fabric Roll digolongkan saat inspeksi ("Shade" Optitex: A, B, C, …). Ply dalam satu Lay berasal dari satu Shade selama gulungan memungkinkan. | Lot, dye lot, tone |
| **Remnant** | Kain yang tersisa pada Fabric Roll setelah Cut Order mengambil Ply darinya; kembali ke Fabric Room. | Roll end, end bit, leftover, offcut |
| **Purchase Order** | Order buyer di dalam Cut Plan: Order-nya (jumlah), marker sendiri, dan Lay sendiri. Satu Cut Plan memuat satu atau lebih, masing-masing direncanakan terpisah dan dibandingkan berdampingan. Ditulis PO di antarmuka. | Order (itu hanya jumlahnya), job, batch |
| **Spreading Group** | Material sebuah Cut Plan yang dipotong bersama dari satu kain. Material pertama dalam grup memberi lebar, penyusutan, dan biaya, dan satu marker memuat potongan dari semuanya. | Fabric group, material set |
| **Cutting Table** | Meja tempat Cut Plan bisa memotong: panjang, lapis paling sedikit dan paling banyak, dan secara opsional satu Material atau Spreading Group yang dilayaninya. Solve memakai meja terpanjang yang muat, dan Cut Order memberi setiap Lay ke meja yang panjang hamparannya sejauh ini paling sedikit. | Spreading table, cutting bed, Marker Table (itu kanvasnya) |
| **Roll Group** | Fabric Roll satu Material yang direncanakan bersama karena berbagi langkah lebar, penyusutan, atau Shade, sesuai setelan Cut Order. Jumlah setiap warna dibagi ke Roll Group-nya sebanding dengan kainnya, dan setiap grup punya markernya sendiri. | Roll batch, fabric lot |
| **Fabric Room** | Inventaris Fabric Roll bengkel (gudang kain) sebagai berkas CSV atau Excel: kode, Material, warna, Shade, lebar, panjang, penyusutan, pemasok, biaya, dan berat. Cut Plan mengambil gulungan darinya dan menulis Remnant kembali setelah Operator mengonfirmasi. | Warehouse, stock list, roll database |
| **Style Set** | Daftar bernama dari potongan satu Style, setiap baris dengan nama, kode, deskripsi, Material, jumlah, pasangan, dan penyusutan sendiri. Marker atau Cut Plan menanamkan Style Set sebagai Style yang potongannya adalah baris-baris itu. | Piece group, kit, collection |
| **Measurement Chart** | Ukuran-ukuran yang ditetapkan buyer untuk sebuah Style. Satu ukuran menjumlahkan bagian-bagian, masing-masing diambil di antara dua titik potongan pada potongan yang sudah di-grade di setiap ukuran, dan setiap ukuran punya nilai buyer dengan toleransi bawah dan atas. Rajutara memeriksa potongan terhadap chart itu dan tidak pernah mengubah potongan agar sesuai. | Size chart, spec sheet, POM table |
| **Size Variation** | Satu set ukuran tambahan dengan grading sendiri, disimpan di samping Size Table utama (misalnya panjang Short, Regular, dan Long). Selama satu variasi aktif, Sizes Table dan alat grading menyuntingnya; Reshape Variation Grading menggabungkan semuanya menjadi satu Size Table berisi ukuran gabungan. | Size group, size run, fit |
| **Merged Base Size** | Base Size sebuah Style yang digabung ke Style lain oleh Cross Grading, ditandai "*" di Sizes Table dan Grading Table. Potongan yang digabung mempertahankan geometrinya pada ukuran itu dan delta miliknya sendiri; potongan itu tidak bergerak di ukuran-ukuran Style yang dimasukinya. | Second base, extra base |
| **Stripe Definition** | Garis belang atau kotak-kotak kain di Marker Table: titik mulainya, jarak antara belang vertikal dan antara belang horizontal, dan sudut masing-masing. Dengan Stripe Adjust aktif, titik cocok potongan yang ditata jatuh di persilangan belang. | Check pattern, fabric grid |
| **Folded Piece** | Potongan yang ditata terlipat di Marker Table: sepanjang tepi atas atau bawah (Tubular, Folded), sepanjang tepi kiri atau kanan (Faced, Folded), atau sebagai seperempat di sudut (Folded, empat Ply atau lebih). Potongan itu adalah separuh di sisi meja dari garis lipatnya, dan salinan berikutnya dari potongan yang sama yang masih menunggu menjadi pasangannya, terlipat bersamanya. | Half piece (itu separuh tersimpan dari Mirror Line), mirrored piece |
| **Side Buffer** | Buffer tambahan di satu sisi Piece: Up, Down, Left, atau Right dari bingkai seratnya, dengan opsi Convex dan Round Corners. Sisi-sisinya ikut berputar bersama potongan, dan salinan cermin menukar Up dan Down. Buffer Chain memberi satu ruas kontur Buffer-nya sendiri. | Edge buffer, offset |
| **Lane** | Salah satu dari paling banyak enam pita melintang lebar Material (lajur) tempat Auto Nesting menjaga Bundle utuh, sehingga potongan satu garmen berasal dari satu pita kain bila warna berubah melintang lebar kain. Bundle k masuk ke Lane k mod n, dan potongan boleh keluar dari Lane-nya sejauh Lane overlap. | Column, strip, horizontal group |
| **Cut Elsewhere** | Potongan sebuah order yang dipotong Marker lain dari order yang sama (Auto Save Of Markers). Marker menyembunyikannya, tidak pernah me-nesting-nya, dan tidak menghitungnya sebagai hilang. | Excluded piece, hidden piece |
| **Notch Preset** | Penandaan yang disimpan: bentuk, kedalaman, lebar, Top Width, Reverse, dan perintah, dipilih menurut nama di Notch Tool dan Notch Properties. Preset disimpan di Preferences, jadi setiap Style memakai daftar yang sama. | Notch template, favourite notch |
| **Command Layer** | Satu set alat bertipe yang dipakai skrip batch, server MCP, Playbook, dan asisten untuk membaca dan mengubah dokumen (lapisan perintah). Setiap alat punya nama, skema JSON, Tool Tier, dan Role yang boleh menjalankannya, dan setiap perubahan melewati Undo. | API, plugin interface, scripting layer |
| **Tool Tier** | Tingkat sebuah alat Command Layer: basic, standard, atau advanced. Sesi menetapkan Tool Tier tertinggi yang boleh dipanggilnya. | Level, permission |
| **Role** | Peran yang dijalankan sesi Command Layer: Designer, Grader, Marker maker, Cutter, atau Supervisor. Setiap alat mendaftar Role yang boleh menjalankannya; Supervisor adalah bawaan dan menjalankan semuanya. Di jendela, Role yang dipilih di bilah status juga menonaktifkan aksi menu di luarnya; Role memandu Operator dan bukan kontrol akses. | User level, account, permission |
| **Approval Policy** | Ask atau Yolo. Dengan Ask, bawaannya, alat yang menyimpan, menimpa, menghapus, atau membuang menunggu konfirmasi Operator. Yolo melewati pertanyaan dan Approval Checkpoint tetapi selalu menyimpan cadangan, sampah, dan log aksi. | Auto-approve, trust mode, autopilot |
| **Untrusted Text** | Teks yang berasal dari berkas atau Attachment (nama potongan, catatan, teks DXF, sel spreadsheet, nama buyer dan PO). Teks ini sampai ke pemanggil Command Layer hanya sebagai bidang bernomor tersendiri. Teks ini adalah data: tidak pernah menjadi instruksi, dan perintah yang merusak tidak pernah mengambil targetnya dari teks ini tanpa konfirmasi Operator. | User input, external text, content |
| **Attachment** | Berkas yang diserahkan ke sesi Command Layer (lampiran): PNG, JPEG, PDF, CSV, atau XLSX, dikenali dari isinya, dengan id, batas ukuran, dan hash. Attachment dihitung sebagai data yang tidak tepercaya. | Upload, enclosure |
| **Playbook** | Resep TOML berisi tahap bernama dengan parameter, pemeriksaan, dan Approval Checkpoint, dijalankan lewat Command Layer dengan atau tanpa model. Statusnya disimpan setelah setiap tahap, sehingga run yang terputus bisa dilanjutkan, dan setiap run menulis Run Record. | Macro, workflow, script |
| **Approval Checkpoint** | Titik dalam Playbook tempat run berhenti dan meminta Operator melanjutkan, memilih, atau berhenti. Approval Policy Yolo melewatinya. | Confirmation, gate |
| **Quick Action** | Awal Playbook bernama dengan parameter yang sudah terisi (aksi cepat), ditawarkan sebagai satu pilihan: misalnya optimasi marker dengan algoritme cepat dan batas waktu bengkel. | Shortcut, preset, macro |
| **Run Record** | Berkas yang ditulis run Playbook: versi aplikasi, versi dan hash Playbook, hash Workshop Profile, versi Prompt File, id model, dan seed nesting. Memutar ulang Run Record mengulang run. | Log, audit trail, history |
| **Workshop Profile** | Satu berkas TOML berisi standar bengkel, berlabel bahasa Indonesia (profil bengkel): kampuh per jenis jahitan, penyusutan, batas lapis, buffer potongan, target efisiensi, dan toleransi QC. Playbook dan asisten membacanya, dan nilai tanpa sumber dilaporkan sebagai perlu konfirmasi Operator. | Settings, factory config, template |
| **Assistant Memory** | Yang disimpan asisten antarsesi: pelajaran, preferensi, fakta, dan koreksi, tersimpan di PC ini di folder konfigurasi dan, bila diinginkan, di `.rajutara/memory/` sebuah proyek. Hasil dokumen dan alat mengalahkan Workshop Profile, yang mengalahkan memori; memori yang bertentangan dengan keduanya ditandai usang. | History, chat log, cache |
| **Knowledge Index** | Indeks pencarian lokal (BM25, tanpa model embedding) atas SOP bengkel dan manual buyer sendiri (teks PDF, TXT, MD, dan DOCX), disebut indeks pengetahuan. Berkasnya dibaca dan tidak pernah diubah, dan pencarian mengembalikan cuplikan, yang merupakan Untrusted Text. | Library, wiki, vector store |
| **Prompt File** | Sumber teks berversi yang memberi tahu model siapa Rajutara dan cara menjawab: satu berkas inti (di bawah 600 token), satu per Role (di bawah 400), satu per Knowledge Skill (di bawah 400), satu per gaya bicara Persona (di bawah 120), dan satu per tahap Playbook. Salinan yang dikelola di folder konfigurasi mengalahkan berkas bawaan, dan versi serta hash-nya masuk ke Run Record. | System prompt, template |
| **Action Contract** | Aturan bahwa model menjawab dengan tepat satu aksi JSON per giliran: alat dengan argumennya, satu kalimat untuk diucapkan, atau pertanyaan kepada Operator dengan dua sampai enam pilihan. Command Layer memeriksanya terhadap skema alat dan alat yang diizinkan tahap itu sebelum apa pun berjalan. | Output format, protocol |
| **Answer Template** | Pesan Fluent (`answer-<tool>`, bahasa Inggris dan Indonesia) yang mengubah hasil sebuah alat menjadi kalimat yang dibaca Operator. Angkanya berasal dari hasil dan diformat dengan format angka Operator; tidak ada teks model yang masuk. | Summary, response text |
| **Prompt Preview** | Semua isi sebuah prompt, didaftar untuk Operator: instruksi, alat, pelajaran, cuplikan pengetahuan, kutipan dokumen, hasil alat, ukuran, dan penyamaran. Sebelum permintaan keluar dari PC, jendela persetujuan menampilkan daftar ini bersama permintaan persisnya, dan hanya Kirim dari Operator yang melepaskannya (lihat Consent). | Debug view, dry run |
| **Redaction** | Penggantian nama buyer, kode PO, dan harga di prompt dengan placeholder (⟦BUYER_1⟧, ⟦PO_1⟧, ⟦PRICE_1⟧) sebelum sampai ke penyedia model (penyamaran). Petanya tetap di PC ini dan mengembalikan placeholder di balasan model. | Anonymising, masking, scrubbing |
| **Assistant** | Panel di samping ruang kerja tempat Operator mengetik tugas dan model mengerjakannya lewat alat Command Layer, satu Action Contract setiap kali (asisten). Asisten mati sampai Operator memilih Model Profile. Aksi cepat, penjalan playbook, dan perbandingan skenario ada di sampingnya dan tidak butuh model. | Chatbot, copilot, AI |
| **Model Profile** | Satu cara bernama untuk memanggil model (profil model): Provider Kind, alamat, nama model, header masuk, rujukan kunci, header tambahan, mode jawaban, batas, batas waktu, dan harga. Operator menyimpan beberapa dan menandai satu sebagai bawaan; kuncinya sendiri tidak pernah ada di profil. | Connection, account, endpoint |
| **Provider Kind** | API yang dipakai sebuah Model Profile (jenis penyedia): `ollama`, `llama-cpp`, `openai-compatible`, `openai-responses`, `anthropic`, atau `gemini`. Banyak vendor berbagi satu jenis; Groq, DeepSeek, dan LM Studio semuanya memakai `openai-compatible`. | Vendor, backend, driver |
| **Preset** | Titik awal yang mengisi Model Profile baru untuk satu penyedia: jenis, alamat, header masuk, versi API, dan mode jawaban. Ada dua belas preset. Setiap isian yang diisinya tetap bisa diubah, dan profil tidak mengikuti perubahan preset di kemudian hari. | Template, default, connector |
| **Egress** | Ke mana sebuah permintaan pergi. Local berarti PC ini (hanya loopback); Remote berarti host lain mana pun, termasuk jaringan Operator sendiri. Setiap permintaan Remote memerlukan Consent. | Cloud, online, external |
| **Consent** | Kirim dari Operator untuk satu permintaan Remote (persetujuan), terikat pada SHA-256 metode, URL, dan isinya. Consent hanya berlaku untuk permintaan itu; percobaan ulang atau permintaan yang berubah bertanya lagi. | Permission, opt-in, allow |
| **Knowledge Skill** | Apa yang diketahui satu giliran asisten (keahlian): Prompt File, daftar alat yang pendek, tag pengetahuan yang dicari lebih dulu, dan lingkup memori asal pelajarannya. Ada delapan: pembuatan pola, grading, marker, ruang potong, bahan, QC, pertukaran berkas, dan pengajar, yang menjelaskan cara mengerjakan sesuatu. | Agent, plugin, mode |
| **Persona** | Cara asisten berbicara: nama tampilan dan gaya bicara, Formal (Anda) atau Santai (kamu). Persona hanya mengubah kata-kata, tidak pernah mengubah alat yang dijalankan. | Character, personality, voice |
| **GUI Socket** | Pendengar di 127.0.0.1, mati sejak awal, yang mengizinkan satu program lokal dengan token dari folder konfigurasi memakai jendela yang berjalan lewat MCP (soket lokal).
