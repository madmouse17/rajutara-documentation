## [2.0.0] - 2026-11-06

Wave C: butir v2.0 dari `docs/spec/08-v2-roadmap.md` §3.2, butir v2.x X3, X4, X6, X7, X9, X10, X13, dan X14, variasi ukuran, Cross Grading, dan lapisan perintah agen. Berkas yang disimpan rilis ini adalah format native 3, yang tidak bisa dibuka 1.5.x dan yang lebih lama (lihat Diubah).

### Ditambahkan
- **PDS: preset penandaan dan Top Width** (`docs/spec/02-pds.md` §12.1, Optitex O/26.1). Dialog Notch Tool dan Notch Properties mendapat Preset dan Save as Preset…; View › Notch Presets… mengganti nama dan menghapusnya. Preset menyimpan bentuk, kedalaman, lebar, Top Width, reverse, dan perintah. Preset disimpan di Preferences, jadi setiap Style melihat daftar yang sama. Penandaan Box mendapat Top Width, lebarnya di ujung (kosong berarti sama dengan lebar), digambar di Work Area, di plot, serta di plot dan berkas potong Marker.
- **PDS: filter Change Multiple Internal Attributes** (T51, O/25.1): Min dan Max untuk kedalaman, lebar, dan Top Width penandaan, serta untuk jari-jari lubang bor.
- **PDS: Auto Renumber** (Preferences › PDS › Copied pieces). Paste dan Save Active as New memberi salinan akhiran `_n` sumber ditambah satu, atau `_1`, dan terus menghitung selama nama itu sudah dipakai. Standard copy mempertahankan penamaan lama.
- **PDS: Segment Length dari kedua ujung** (T43, O/26.1). Moving end Both ends menggeser setiap ujung setengah dari perubahan. Extend By Curve ditolak dengan Both ends.
- **PDS: Switch Cut/Sew bertanya dulu** (O/26). Switch Cut/Sew dan Switch Pieces to SEW/CUT menyebut berapa potongan yang garis tersimpannya berubah dan meminta Continue, dengan Do not ask again. Preferences › PDS › Confirm switching between sew and cut lines memunculkan pertanyaannya lagi.
- **PDS: Style Set** (`docs/spec/02-pds.md` §12.3, View › Style Set, tombol `4`). Style Set mendaftar potongan, setiap baris dengan Code, Description, Material, Quantity, Pair, dan X/Y Shrink sendiri. Panelnya punya bidang cari (huruf besar-kecil dan aksen diabaikan), Create, Remove, Duplicate (`@<name>`), Description, Add Pieces (satu potongan boleh ditambah dua kali), Remove Pieces, dan Place, yang hanya menaruh potongan set itu di meja dan menatanya untuk plot. Setiap suntingan adalah satu langkah urungkan. New Marker, Marker Creation Wizard, dan Cut Plan › Add Style bisa menanamkan satu set alih-alih seluruh Style, dan Update from Style mempertahankan set itu.
- **PDS: Production Sheet** (File › Production Sheet…, X4). PDF A4 berisi data Style (Author, Date, Sizes, Base Size, Notes), tabel potongan (Name, Code, Description, Quantity, Pair, Material, Area, Perimeter pada Base Size), gambar potongan Base Size, dan satu tabel per Measurement Chart.
- **PDS: Plot ke DXF** (ADR-0017). Dialog Plot mendapat target DXF (rilis 12, milimeter, warna dari pena Plotter Setup) dan mengingat target terakhir. Translate piece names mencetak nama lewat Piece Name Dictionary.
- **PDS: lubang bor dan teks per ukuran** (O/24, O/21). Drill Hole Properties › Appearance in sizes punya satu centang per ukuran; Annotation Properties › Text in sizes punya satu bidang per ukuran (kosong berarti teks utama). Plot, DXF graded nest, Marker, dan tampilan Grading mengikuti setiap ukuran, dan Work Area menandai lubang yang tidak ada di ukuran yang ditampilkan dengan silang kecil. DXF Base Size dengan berkas aturan tidak bisa memuat ini, jadi ia menulis semua lubang dan teks utama dan menyebutkannya di catatan ekspor.
- **Grading: Size Variation** (`docs/spec/03-grading.md` §12.1, Grading › Sizes Table). Current Size Variation, Insert, Append, Delete, dan Name. Selama satu variasi aktif, Sizes Table, alat Grading, dan Graded Nest bekerja pada ukuran dan delta variasi itu. Grading › Reshape Variation Grading mengubah variasi menjadi satu daftar ukuran bernama `<variation size>-<main size>`, dan ditolak di atas 99 ukuran. Marker dan Rencana Potong baru melihat ukuran variasi setelah Reshape.
- **Grading: Cross Grading** (§12.2, Merge Style File › Special Merge Sizes List). Style mempertahankan ukurannya dan mendapat ukuran lain dari berkas yang digabung dalam urutan berkas. Base Size berkas itu ditandai `*` di tabel ukuran, dan penggabungan adalah satu langkah urungkan.
- **Grading: Measurement Chart** (§12.3, View › Measurement Charts, Grading › Measure Definition). Beberapa chart per Style. Satu ukuran-ukur adalah jumlah bagian-bagiannya dikali faktor; satu bagian berjalan di antara dua titik pada satu potongan, diambil Along Contour, Straight, Horizontal, atau Vertical, di setiap ukuran. Toleransi − dan +, spesifikasi buyer per ukuran dengan baris Spec dan Diff, dan nilai di luar spesifikasi yang terbaca `OUT +5.0` sebagai teks, bukan hanya warna. Import Spec… membaca `.csv`, `.xlsx`, atau `.ods`; Report… dan Out of Spec Report… menulis `.csv`, `.xlsx`, atau `.pdf`. Chart disimpan di Style. Tidak ada yang diubah ukurannya (ADR-0004).
- **Grading: L-notches as L shapes** (§12.4, Export Graded Nest, O/26). Mati secara bawaan. Bila menyala, penandaan L juga menulis garis tepi berbentuk L sebagai polyline di samping titiknya.
- **Marker: Algorithm** (`docs/spec/04-marker.md` §6.3, §6.5, ADR-0019). Auto Nesting Setup menawarkan Standard, Standard Quick (hanya putaran awal dan pemadatan), dan Advanced (minimisasi tumpang-tindih pada no-fit polygon setelah awal Standard; mengembalikan yang lebih baik dari keduanya). Advanced adalah bawaan (lihat Diubah).
- **Marker: log efisiensi dan marker sementara** (O/25). Auto Nesting Setup › Write efficiency log (CSV) menulis `<stem>-nesting.csv` (`time_s,length_mm,efficiency_pct,placed`, satu baris per perbaikan), dan Save interim markers menulis ulang `<stem>-interim.rjm` dengan susunan terbaik paling sering sekali semenit. Keduanya memerlukan Marker yang sudah disimpan.
- **Marker: pengelompokan bundle, lajur, dan opsi blok** (§6.5, Auto Nesting Setup › Grouping). Nesting According To Bundles, Groups According to Sizes, Bundles Overlap (Small, Medium, Large), Maintain Piece Orientation Within Bundles, Horizontal Groups (1 sampai 6 lajur melintang lebar) dengan Horizontal Groups Overlap, dan Block Fuse During Nesting (Regular, Nest Blocks First, Nest Blocks Last, Nest Blocks Only, Nest With No Blocks) dengan Separate Blocks. Pilihan Grouping dan lajur disimpan di Marker; Block Fuse During Nesting dan Separate Blocks hanya bertahan selama sesi. Dengan lajur, area bundle setiap lajur berjalan berdampingan dengan lajur lain.
- **Marker: Edit Piece Buffer** (§5.8, menu Piece, O/19). Around, Convex, Up, Down, Left, dan Right, rantai garis potong yang dipilih One by One atau Start-End dengan lebarnya sendiri, dan Round Corners; Apply to Selected Pieces atau Apply to All Pieces, satu langkah urungkan. View › Piece Buffer menggambar garis tepi yang sudah diberi buffer. Potongan tanpa buffer sisi dan tanpa rantai di-nesting persis seperti sebelumnya.
- **Marker: potongan terlipat** (§5.9). Piece › Foldable Up & Down (`Ctrl+U`), Foldable Left & Right, dan Not Foldable (`Ctrl+Q`) mengatur aturan salinan di Marker. Piece › Place Folded menawarkan empat tepi dan empat sudut, atau tahan `U`, `D`, `L`, atau `R` saat menjatuhkan atau mengklik ganda potongan yang menunggu (dua tombol membuat sudut). Mode lapis menentukan tepinya: Tubular melipat di atas dan bawah, Faced di kiri dan kanan, Folded di keempatnya, dan sudut memerlukan Folded dengan 4 lapis atau lebih; tepi kanan memerlukan panjang Marker. Pasangan terlipat adalah dua salinan yang berbaring sebagai satu separuh pada garis lipat. Klik ganda, atau pakai Piece › Unfold, untuk mengembalikan keduanya. Plot dan berkas potong menggambar separuh itu dengan tanda lipat, dan Auto Nesting membiarkan potongan terlipat di tempatnya.
- **Marker: garis dan kotak-kotak** (§5.10). Marker › Stripe Definition… (Start X dan Y, jarak antara garis vertikal dan horizontal, kedua sudut, Stripe Adjust According To Set Only), View › Stripes Lines, Tools › Stripe Adjust, Marker › Relate Piece to Stripes…, dan Grouping › Stripe Adjust Group (`Ctrl+G`). Dengan Stripe Adjust menyala, potongan yang punya titik garis menempel ke garis saat dijatuhkan, diseret sendirian, ditembak, atau dimasukkan ke lubang, dan Auto Nesting menempatkan potongan seperti itu hanya di posisi garis.
- **Marker: Tilt** (§5.11). Piece › Tilt Left (`F11`) dan Tilt Right (`F12`) memutar potongan terpilih yang sudah ditata sebesar Tilt Step dari Preferences › Marker, dalam batas Max Tilt potongan (PDS Piece Properties atau Piece List Marker, dalam derajat), dalam satu langkah urungkan. Preferences › Marker › Ignore Automatic Tilt Rotations menyala; bila dimatikan, Auto Nesting juga mencoba setiap orientasi yang dimiringkan sebesar Max Tilt ke kedua arah.
- **Marker: Auto Save Of Markers** (§6.8, menu Nesting). Bila menyala dan panjang Marker diisi, Start AutoNesting meninggalkan susunan pertama di Marker yang terbuka dan me-nesting yang tidak muat ke `<file>-1.rjm`, `<file>-2.rjm`, dan seterusnya, sampai setiap potongan tertata atau satu putaran tidak menata apa pun. Potongan yang dipotong oleh marker lain dari rangkaian ini berstatus "cut elsewhere": disembunyikan dari Piece Bar, tidak di-nesting, dan tidak dihitung hilang. Save Only Nested Pieces (And Zero Remainders) dan Write Log Report To File (satu baris CSV per marker yang disimpan) adalah opsi, dan ringkasan mendaftar berkasnya dengan tombol Open.
- **Marker: Export to CAD/CAM Files…** (§9.3, menu File, ADR-0017). DXF (rilis 12, milimeter) dari isi plot, label sebagai teks, satu warna per Bundle, dan satu layer per jenis elemen. Translate piece names memakai Piece Name Dictionary.
- **Marker: Customize Excel Report…** (§8.3, menu File). Satu tab per tabel laporan; setiap kolom punya Show, Title, Move Up, dan Move Down, ditambah Restore Defaults. Pilihan disimpan di Preferences, dan laporan Excel dan PDF mengikutinya.
- **Marker: Piece Description** (§9.4, Preferences › Marker). Bidang (Style Name, Piece Name, Code, Size, Bundle, Material, Description Text) dalam urutan yang Anda atur, Multi-Line Piece Description, Separator, Alphabetical Bundle Names, Don't Reset Bundle Numbering for Each Size, Orientation Next to Bundle Number, Auto Adjust Description Text, dan Show Piece Description Text in non-flipped form. Tabel, plot, label berkas potong, dan ekspor DXF mengikutinya.
- **Rencana Potong: Purchase Order** (`docs/spec/05-cutplan.md` §11, Optitex O/26.1). Satu rencana memuat satu PO atau lebih, masing-masing dengan Order, jumlah, marker, dan Lay sendiri. Panel Plan mendaftarnya dengan Add PO, Duplicate PO, Rename, dan Remove PO (PO terakhir tetap ada). Solve dan Nest Markers bekerja pada PO terpilih; Solve All POs dan Nest All POs bekerja pada setiap PO, masing-masing dalam satu langkah urungkan. Dengan dua PO atau lebih, panel Results menampilkan perbandingan PO (satu kolom per PO dan Total) di atas marker dan Lay PO terpilih, dan laporan membawa satu set bagian per PO ditambah perbandingannya.
- **Rencana Potong: beberapa Style dan Material** (§12). Cut Plan › Add Style… menambah Style dari PDS atau berkas, utuh atau sebagai satu Style Set, dan setiap baris warna menyebut Style-nya; Styles and Materials… mendaftarnya dan menambah Material. Setiap Material direncanakan sendiri kecuali Spreading Group memotong beberapa Material dari satu kain.
- **Rencana Potong: Spreading Groups…, Cutting Tables…, dan pengelompokan gulungan** (§12). Spreading Group memotong Material-nya dari satu kain (lebar, penyusutan, dan biaya Material pertama), jadi markernya memuat potongan dari semuanya. Cutting Tables (nama, panjang, lapis, kain opsional) memberi kain batas dari mejanya yang terpanjang, dan Cut Order menaruh setiap Lay di meja yang muat dengan kain terhampar paling sedikit sejauh ini. Pengelompokan gulungan di panel Cut Order membagi setiap warna ke kelompok gulungan menurut langkah lebar, penyusutan, dan shade, masing-masing direncanakan pada lebarnya sendiri dengan markernya sendiri.
- **Rencana Potong: Fabric Room** (§13, Cut Plan › Fabric Room…; berkasnya diatur di Preferences › Cut Plan). Inventaris gulungan yang dipakai bersama antarrencana, dalam `.csv` atau `.xlsx`: Add, Remove, Import, Export, disaring menurut Material dan warna rencana. Take Rolls menyalin baris ke rencana. Return Remnants bertanya dulu, lalu menulis kembali sisa dari Cut Order: gulungan menjadi lebih pendek dan ringan, dan gulungan yang habis dihapus.
- **Rencana Potong: Customize Report…** (§14). Sembunyikan, ganti nama, dan ubah urutan kolom setiap tabel laporan, sama di CSV dan PDF.
- **Impor spreadsheet membaca `.xlsx` dan `.ods`** selain `.csv` (X14): jumlah dan Fabric Roll Rencana Potong, Fabric Room, spesifikasi Measurement Chart, dan Piece Name Dictionary. Sheet pertama yang dibaca.
- **Pencarian Preferences** (`docs/spec/07-ui-shell.md` §10, O/24). Bidang di atas daftar halaman menemukan pengaturan menurut namanya dalam bahasa antarmuka atau bahasa Inggris, mengabaikan huruf besar-kecil dan aksen; hasilnya terbaca "Halaman › Bidang".
- **Tools › Piece Name Dictionary…** (O/21.4). Tabel Name → Translation dengan Add, Remove, Import, dan Export (`.csv` atau `.xlsx`), disimpan di Preferences. Plot PDS dan Marker serta Export to CAD/CAM mencetak terjemahan dari nama yang persis sama bila Translate piece names menyala.
- **Penunjuk lebih besar di layar HiDPI.** Penunjuk alat digambar 48 px alih-alih 32 px mulai skala layar 1.5×.
- **`rajutara batch SCRIPT`** (`docs/spec/07-ui-shell.md` §1.1, ADR-0016). Menjalankan skrip tanpa jendela: satu `@COMMAND /KEY=VALUE` per baris, dengan nama batch Marker Optitex bila Optitex punya perintahnya (`@OPEN`, `@NEST`, `@SAVE`, `@PLOTTER`, `@REPORT`, `@EXPORT`, dan lainnya) dan nama menu untuk perintah Style dan Rencana Potong (`@OPENSTYLE`, `@EXPORTGRADEDNEST`, `@PRODUCTIONSHEET`, `@SOLVE`, `@NESTMARKERS`, `@CUTPLANREPORT`, dan lainnya). Perintah atau kunci yang tidak dikenal menghentikan skrip sebelum apa pun berjalan (exit 1). Baris yang gagal mencetak galatnya dan skrip berlanjut kecuali `@XOE` datang lebih dulu (exit 2). Simpan, timpa, dan hapus memerlukan `--yes`. Opsi: `--log FILE`, `--json`, `--role ROLE`, `--root DIR`.
- **`rajutara mcp`** (ADR-0020). Melayani lapisan perintah ke klien MCP lewat stdin dan stdout (protokol 2026-07-28, ditambah jabat tangan 2025-11-25 dan 2025-06-18). `--tier basic|standard|advanced` membatasi alat yang didaftarnya. Server tidak melakukan panggilan jaringan.
- **`rajutara playbook`** (ADR-0021): `list`, `show`, `start`, `step`, `resume`, `replay`, `quick`, dan `compare`. Empat playbook disertakan: `impor-periksa` (Impor dan periksa), `qc-pola` (QC pola), `pesanan-siap-potong` (Pesanan ke siap potong), dan `optimasi-marker` (Optimasi marker). Sebuah run menyimpan statusnya setelah setiap tahap di folder asisten, berhenti pada persetujuan atau pilihan (exit 3), dan `replay` mengulangnya dengan parameter dan seed nesting yang tercatat. `compare` menjalankan satu tahap atas beberapa set parameter dan tidak mengubah dokumen.
- **`rajutara kb`**: `add`, `search`, `list`, dan `remove` mengelola indeks pengetahuan lokal berisi SOP dan manual buyer (PDF dengan lapisan teks, DOCX, TXT, MD), dicari dengan pemeringkatan kata (BM25). `remove` memerlukan `--yes`.
- **Lapisan perintah agen** (`docs/spec/07-ui-shell.md` §15, ADR-0020) di balik batch, MCP, dan playbook: 85 alat bertipe dengan skema JSON, mencakup dokumen, PDS, grading, Marker, Rencana Potong, biaya (pemakaian kain, biaya per garmen), pemeriksaan QC, playbook, indeks pengetahuan, dan memori. Peran: Designer, Grader, Marker maker, Cutter, dan Supervisor (bawaan, yang menjalankan semuanya). Setiap perubahan melewati Undo dokumen; satu rencana, satu tahap playbook, atau satu panggilan alat PDS adalah satu langkah urungkan per dokumen.
- **Profil bengkel** `profil-bengkel.toml` (label berbahasa Indonesia): 13 standar bengkel (kampuh, penyusutan, batas lapis, buffer potongan, target efisiensi, waktu nesting, toleransi QC) yang dipakai playbook sebagai nilai bawaan. Belum ada yang punya sumber, jadi semuanya dilaporkan sebagai "perlu konfirmasi operator" sampai bengkel mengisi sumbernya.
- **Memori asisten dan berkas prompt** (ADR-0021, ADR-0022). `memory_learn`, `memory_recall`, dan `memory_forget` menyimpan pelajaran, preferensi, fakta, dan koreksi di komputer ini, di `<config>/rajutara/assistant/memory/` atau di `.rajutara/memory/` sebuah proyek. Berkas prompt (satu prompt inti dan satu per peran) berversi, dan salinan milik bengkel di `<config>/rajutara/assistant/prompts/` mengalahkan yang disertakan. Model harus menjawab dengan satu aksi JSON per giliran, yang diperiksa lapisan terhadap skema, peran, dan tier alat. Rilis ini tidak memanggil model.

### Diubah
- **Format native 3** (ADR-0018). Setiap Style, Marker, dan Rencana Potong yang disimpan rilis ini adalah format 3. rajutara 1.5.x dan yang lebih lama menolak berkas seperti itu dengan "made by a newer rajutara (format version 3; this build reads up to 2)" alih-alih membuang data. Berkas dari 1.5.x dan yang lebih lama terbuka seperti biasa, dan Rencana Potong lama menjadi satu Purchase Order. Aplikasi memperbarui dirinya sendiri, jadi perbarui setiap PC yang berbagi berkas pada saat yang sama.
- Kartu sambutan menampilkan versi di samping nama, misalnya "Rajutara 1.5.1".
- **"Cut Plan" kini dua kata** di menu, halaman preferensi, dan laporan: Generating a Cut Plan Report (CSV) dan (PDF); "Laporan Rencana Potong" dalam bahasa Indonesia. Palet perintah tetap menemukan ejaan Optitex.
- **Geometri PDS yang dulu dihampiri kini tepat** (`docs/spec/02-pds.md` §12.6). Titik Build Piece pada Internal Line mengambil grading yang diinterpolasi sepanjang garis itu. Remove Excess Cloth memutar garis dalam, lubang bor, dan teks dari area yang dipindah bersama Grade Rule-nya. Convert Sew Internals To Seam memindahkan kup, lipit, dan garis cermin ke garis jahit baru, atau membiarkannya sebagai objek dalam dan menyebut alasannya. Penandaan yang jangkarnya dipasang ulang oleh suntingan titik tetap di tempatnya di setiap ukuran. Paste antar-Style dengan Base Size berbeda mempertahankan setiap ukuran di tempatnya. Extend in Parallel menyambung tetangga yang tidak terjangkau dengan langkah lurus dan menyebut titiknya. Pleat Lines mempertahankan geometrinya, karena tidak ada sumber publik yang menjelaskannya.
- **Marker: bentuk jamak dan label UTC.** Hitungan terbaca "1 piece" dan "2 pieces". Kolom log Auto Save adalah `date_utc`, dan label laporan dan plot terbaca "Date (UTC)".
- **Marker: Efficiency langsung Auto Nesting** diukur sama seperti hasilnya, jadi kemajuan tidak lagi terbaca lebih tinggi dari hasil.
- **Marker: Advanced menjadi Algorithm bawaan** (`docs/spec/04-marker.md` §6.4, ADR-0019). Auto Nesting, Auto Nest Queue, `@NEST` tanpa `/AL`, dan `marker_nest` tanpa `algorithm` memakai Advanced, yang mengungguli Standard pada kelima tolok ukur ESICUP dengan rata-rata 2,54 poin (angkanya di §6.4). Standard dan Standard Quick tetap ada di daftar Algorithm.
- **Marker: Update from Style** menghitung pasangan terlipat yang dibukanya, di pratinjau dan pemberitahuannya, memeriksa ulang berkas sumber sebelum menjawab, dan menyebut berkas sumber yang hilang.
- **Marker: lebih banyak kolom.** Piece List mendapat Max Tilt (°), Folding, dan Side buffers; laporan mendapat Lane di Order serta Tilt (°) dan Folded di Pieces. Panjang di Piece List memakai satuan kerja. Auto Nest Queue mendapat kolom Algorithm dan Block Fuse.
- **Laporan Rencana Potong dengan beberapa PO** menaruh nama PO sebelum setiap bagian dan menamai berkas CSV `<stem>-<po>-<part>.csv`; Save Markers menulis `<stem>-<po>-M<n>.rjm`. Laporan satu PO sama seperti sebelumnya.
- **Rencana Potong: "Setup changed: solve again".** Setelah Spreading Groups, Cutting Tables, atau pengelompokan gulungan diubah pada rencana yang sudah diselesaikan, bilah status menampilkan bidang ini; satu klik menjalankan Solve All POs. Marker dari grup yang ditinggal tanpa Material mempertahankan kain asal potongnya.
- **Membaca workbook menambah satu dependensi**, `calamine` 0.38 (baris ADR-0006 di `Cargo.toml`); penulis `.xlsx` tetap milik rajutara sendiri.

### Diperbaiki
- **Piece List Marker dan panel Order: angka yang diketik dan diseret bertahan.** Sel Quantity, Buffer, dan Bundles dulu kembali ke nilai tersimpan selama Anda mengetik atau menyeret. Kini sel mempertahankan nilainya dan menerapkannya sekali, saat `Enter`, di akhir seretan, atau saat Anda mengklik di tempat lain; `Esc` membuangnya.
- **PDS: penandaan di kampuh potongan garis-jahit bisa dipilih.** Pemilihan kini menguji garis potong, jadi Select dan Properties menjangkau penandaan itu.
- **PDF laporan menjaga judul bersama gambarnya.** Gambar yang tidak muat pindah ke halaman berikutnya bersama judulnya.
- **Rencana Potong: total order kosong terbaca 0.00**, bukan -0.00.

### Keamanan
- **Spreadsheet dibaca dalam batas tetap.** Berkas sheet di atas 20 MB, `.xlsx` atau `.ods` yang terurai lebih dari 256 MB, `.xlsx` yang mendeklarasikan lebih dari 1 000 000 shared string, dan sel di luar baris 100 000 atau kolom 1 000 ditolak, dan paling banyak 1 000 000 sel dibaca. Workbook `.xls` lama tidak dibaca sama sekali: formatnya membiarkan berkas kecil meminta memori bergigabyte. Simpan sebagai `.xlsx` atau `.csv`.
- **Sesi agen tetap di foldernya** (`SECURITY.md`). `batch`, `mcp`, `playbook`, dan `kb` hanya menjangkau berkas di dalam `--root`, bawaannya folder saat ini. Share jaringan atau path perangkat (`\\server\share`, `\\?\UNC\…`, `\\.\…`) ditolak sebelum sistem berkas disentuh, jadi Windows tidak pernah masuk ke share yang disebut berkas rekayasa.
- **Persetujuan dipakai sekali.** Dalam mode Ask, simpan, timpa, hapus, atau buang memerlukan persetujuan operator untuk operasi dan target itu, dan persetujuan habis oleh panggilan itu; rencana yang disetujui mencakup satu run itu saja. Rencana dan playbook menolak langkah undo dan redo.
- **Teks berkas tidak dipercaya.** Teks yang dibaca dari berkas, termasuk nama berkas, hanya sampai ke model di bidang tak-tepercaya tersendiri, dan target terlindungi yang berasal dari teks berkas ditandai demikian di pertanyaan dan catatan keamanan.
- **Cadangan bertahan sehari.** Setiap penimpaan lewat lapisan perintah lebih dulu menulis `<file>.<YYYYmmdd-HHMMSS>.bak`. - **MCP: alat yang panik** menjawab dengan galat internal, lalu server menolak setiap alat tulis sampai dijalankan ulang.

Kontrol tiga tombol (System, Dark, Light) berada di ujung kanan bilah menu; View › Theme dan Preferences › Appearance tetap selaras dengannya. Preferensi kini versi 2; `Light` atau `Dark` yang tersimpan dipertahankan, dan build 1.0 menolak berkas yang lebih baru alih-alih salah membacanya.
- **Pemeriksaan pembaruan dan pembaruan mandiri** (`docs/spec/07-ui-shell.md` §14, ADR-0015). Sekali sehari saat start, diam-diam, Rajutara menanyakan rilis terbaru ke GitHub (`update.repo`, bawaan `madmouse17/rajutara`; Preferences › General mematikannya). Selama rilis yang lebih baru ada, tombol oranye **Update available · v1.x** muncul di kiri kontrol tema dan membuka dialog dengan catatan rilis dan **Download and Install**; Help › Check for Updates… memeriksa atas permintaan dan selalu menjawab. Linux mengganti AppImage secara atomik dan menawarkan **Restart Now**; Windows menjalankan `.msi` lewat `msiexec` setelah **Install and Close**. Dependensi baru `ureq` 3 (`rustls`, `json`; tanpa OpenSSL, tanpa runtime async); `deny.toml` dan `about.toml` mengizinkan `CDLA-Permissive-2.0` (data `webpki-roots`) dan melewati `getrandom` 0.2 yang duplikat. Build debug menghormati `RAJUTARA_FAKE_UPDATE=1.9.9` untuk menampilkan tombol tanpa permintaan.
- **Layar sambutan.** Selama PDS atau Grading belum punya dokumen, Work Area menampilkan kartu dengan logo, **New Style**, **Open…**, **Import DXF…**, **Open sample "Kaos Lengan Pendek"**, dan lima berkas terbaru. Contohnya dikompilasi ke dalam program dan ditulis ke `samples/` di direktori konfigurasi setiap kali dibuka.
- **File › Close** (`Ctrl+Shift+W`) menutup dokumen aktif. Dokumen dengan perubahan belum tersimpan bertanya Save / Don't Save / Cancel lebih dulu (`Esc` adalah Cancel); berkas simpan otomatisnya ikut hilang. Keluar dan tombol tutup jendela bertanya hal yang sama.
- **File › Open Recent** menyimpan 10 berkas terbaru dari setiap jenis (Style, DXF, Marker, Cut Plan), mengelompokkannya menurut jenis, memindahkan berkas ke depan pada setiap buka dan simpan, dan menampilkan berkas yang sudah hilang dalam warna abu-abu. Sebelumnya satu daftar berisi 8.
- **Seret dan jatuhkan:** berkas yang dijatuhkan di jendela terbuka menurut ekstensi (`.rjx`, `.rjm`, `.rjc`, `.dxf`); berkas lain mendapat pemberitahuan.
- **Pencarian Toolbox** (View › Search Tools): menyaring alat secara langsung menurut nama Inggris, Indonesia, atau Optitex; `Enter` menjalankan kecocokan pertama, `Esc` mengosongkan; `/` saat panel Toolbox terfokus, atau mengetik dengan fokus keyboard pada tombol alat, memulai pencarian. Tidak punya chord: `Ctrl+Shift+F` tetap Fold Out milik Optitex.
- **Diganti namanya dari Rajutara.** Berkas dengan ekstensi lama `.optx`, `.optm`, dan `.optc` tetap terbuka (File › Open, seret dan jatuhkan, baris perintah; dialog buka mencantumkannya di bawah "Legacy Rajutara files"); berkas terbuka tanpa judul dan Save menulis `.rjx`, `.rjm`, atau `.rjc`. Pada run pertama, direktori konfigurasi lama `Rajutara` (preferensi, tata letak, jendela) disalin ke `rajutara` sekali. AppImage mendaftarkan tipe MIME untuk keenam ekstensi.
- Tooltip toolbar dan Toolbox berbunyi `Name  · shortcut  · Optitex: name`.
- `Ctrl` + roda menggeser kanvas secara horizontal dan `Shift` + roda secara vertikal; peta roda ada di `docs/spec/07-ui-shell.md` §4.1. Ctrl + roda tidak lagi men-zoom; pinch tetap.

## [1.0.0] - 2026-11-01

Rilis pertama. CAD pakaian clean-room untuk Linux (acuan) dan Windows 7+ (dibuat silang), lihat `docs/adr/`.

### Ditambahkan
- Ruang kerja **PDS**: 89 alat pola (drafting, titik, notch, kampuh, kup, lipit, walk, cermin, pisah/gabung, fullness, spiral, gusset), panel Pieces/Properties/History, Plot (A4 berubin, A0, HPGL/2).
- Ruang kerja **Grading**: Size Table, Grade Rules, Rule Table, tampilan Graded Nest, 29 alat grading, ekspor graded nest ASTM + RUL.
- Ruang kerja **Marker**: penataan manual (seret, putar, balik, bump, Shoot), mesin nesting otomatis (no-fit polygon dengan ring convolution, bottom-left fill, simulated annealing; deterministik menurut seed; `Stop::Time` adalah batas waktu dinding yang keras), laporan marker, plot HPGL/2 dan berkas potong.
- Ruang kerja **Cut Plan**: order (mode rasio, impor CSV), penyelesai perencanaan lay, nesting, konsumsi dan biaya, Cut Order dengan Fabric Rolls (urutan, alokasi gulungan, sisa), laporan CSV/PDF.
- Pertukaran: impor dan ekspor DXF ASTM D6673 / AAMA-292, berkas aturan grade RUL; `.rjx` / `.rjm` / `.rjc` asli (zip + JSON, format 2).
- Shell: panel yang bisa di-dock, palet perintah, pintasan keyboard, tema terang/gelap, UI bahasa Inggris dan Indonesia, simpan otomatis dengan pemulihan setelah crash, pemeriksaan mandiri `--smoke`.
- Pengemasan: AppImage Linux; `.zip` (portabel) dan `.msi` (pemasang) Windows x64/x86 dengan OpenGL perangkat lunak Mesa opsional, Windows 7 SP1 sampai Windows 11.

### Batasan yang diketahui
- Build Windows hanya diverifikasi di bawah Wine dan gerbang impor; uji di perangkat keras nyata masih tertunda.
- 3D (setara Runway) hanya antarmuka (ADR-0005).
- Driver pemotong vendor tidak disertakan; berkas potongnya hanya HPGL/2 generik.
