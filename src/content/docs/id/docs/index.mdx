Rajutara adalah CAD pakaian sumber terbuka: desain pola, grading, pembuatan marker, dan rencana potong dalam satu jendela, untuk Linux dan untuk Windows 7 SP1 sampai Windows 11. Halaman ini ditulis dari spesifikasi di repositori. Setiap angka di dalamnya berasal dari kode, uji coba, atau berkas contoh.
